Minha experiência combina conhecimentos de processos industriais, qualidade, negócios e tecnologia. Utilizo essa visão multidisciplinar para compreender problemas, organizar informações e construir soluções que reduzam tarefas repetitivas e apoiem decisões. Gosto de explorar rapidamente uma ideia, desenvolver um protótipo funcional e aprimorá-lo a partir dos resultados obtidos.
